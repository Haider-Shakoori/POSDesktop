# BusinessOS POS Desktop

Native Windows POS for Afghanistan, built from the existing BusinessOS POS workflows and the PharmaDesktop desktop design/architecture.

## Product rules
- AFN only
- No tax workflow
- English, Dari, Pashto
- Offline-first/local operation
- LAN-ready multi-terminal deployment
- Daily shift and business-day closing
- GitHub Actions validation and release packaging
